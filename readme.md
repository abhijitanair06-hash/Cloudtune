# CloudTune 🎵

CloudTune is a private, cloud-hosted personal music streaming platform.

## Purpose

CloudTune allows one user to store and stream their personal music library from multiple devices.

## Target Devices

- Android phone
- Laptop

## Core Features

- Music library
- Music streaming
- Playlists
- Favorites
- Search
- Listening history
- Queue
- Shuffle
- Repeat
- Multi-device playback synchronization
- Responsive web interface
- Progressive Web App

## Architecture

CloudTune uses a modern web architecture:

- Next.js frontend
- FastAPI backend
- PostgreSQL database
- Docker containers
- Cloud VPS deployment
